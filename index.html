Runs on your computer

metacleaner

Clean files, read scanned PDFs, and improve English writing on your computer.

Install on Linux Download for Windows Source on GitHub

Install (Debian / Ubuntu)

sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://siddhantbhattarai.github.io/metacleaner/pubkey.gpg \
  | sudo tee /etc/apt/keyrings/metacleaner.asc > /dev/null

echo "deb [signed-by=/etc/apt/keyrings/metacleaner.asc] https://siddhantbhattarai.github.io/metacleaner stable main" \
  | sudo tee /etc/apt/sources.list.d/metacleaner.list

sudo apt update
sudo apt install metacleaner

This adds a dedicated apt source signed with a repo-specific GPG key (not a global apt-key entry) — standard practice for third-party apt repositories.

To install the newest package directly, download the .deb release, then run sudo apt install ./metacleaner_*.deb.

Install on Windows

Download and extract the Windows ZIP, then open PowerShell in the extracted folder:

.\metaclean.exe serve

Download the standalone .exe or download the ZIP with instructions and license.

What it does

  • Images (JPEG/PNG/WebP/BMP/GIF/TIFF) — strips EXIF, GPS, XMP, IPTC, C2PA content credentials, and AI-generator signatures (Stable Diffusion, DALL-E, Midjourney, Firefly); optional real AI super-resolution upscaling.
  • Text / Markdown — strips invisible-Unicode steganography (zero-width chars, bidi overrides, Unicode Tag block smuggling) and AI-identifying frontmatter keys.
  • HTML — strips identifying <meta> tags (generator, author) and non-conditional comments.
  • Office documents (DOCX/XLSX/PPTX) — strips author, company, and tracking properties; document content untouched.
  • PDF and DOCX writing — extract text, OCR scanned PDF pages, revise drafts, then export while retaining the source document structure.
  • English writing — General, IELTS, and PTE practice modes with tone and English variety controls, categorized grammar suggestions, criterion-based feedback, and word/form checks.

Use the app

Start the local web app, then drop in a file or choose it from the page:

metaclean serve

Windows: run .\metaclean.exe serve from PowerShell in the extracted folder.

The page opens at http://127.0.0.1:7878. Files stay on your computer.

Command line

metaclean inspect photo.jpg              # report what's present, read-only
metaclean clean photo.jpg                # strip it, writes photo-clean.jpg
metaclean clean-text notes.md page.html  # invisible chars + frontmatter/meta
metaclean clean-doc report.docx          # Office document metadata
metaclean serve                          # open the local web app

Optional tools

  • Scanned PDF OCR: install Tesseract and Poppler (pdftoppm). On Ubuntu: sudo apt install tesseract-ocr poppler-utils.
  • Writing feedback: choose the IELTS/PTE task, English variety, and revision tone in the writing panel. Install Ollama and run ollama pull qwen3.5:9b for local revisions. Optional grammar checks use LanguageTool and Java; run this in its extracted folder:
java -cp languagetool-server.jar org.languagetool.server.HTTPServer --port 8081
